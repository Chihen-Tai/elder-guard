# 家人守門員（暫名 Elder Guard）— 規劃

> 版本 0.5（改由軟體依審核標準判斷，不再依賴問家人；見 REVIEW-STANDARD.md），2026-09-25（新增第 11 節：安裝當下攔查與安全掃 QR；介面依「長輩獨自使用」重新設計）。依據：兩支實機（OPPO Reno10 Pro / Android 15、vivo V2417 / Android 16）的診斷結果，以及對現有產品的調查。

## 1. 要解決的問題

長輩被「你的手機有問題」一類的廣告或彈窗誘導，安裝廣告流氓 App 或詐騙 App。

- **台灣**：主要是從 **Google Play 正常安裝**。Play Protect 不會攔，因為這些 App 在技術上符合 Play 的政策。實機案例：假防毒、救援 App、PDF 閱讀器、清理工具，以及假加密貨幣投資平台 TGC
- **中國大陸**：APK 直接安裝、快應用、搖一搖廣告，規模更大

**現有工具的空白**：Play Protect、反詐中心只比對「已知惡意」清單；純淨模式只管安裝來源；Family Link 不能監護成人。**沒有工具會主動判斷「這是廣告或詐騙型 App」，並當場通知遠端家人。**

## 2. 目標與非目標

**目標（MVP）**
1. 新 App 安裝後 15 分鐘內，在手機上完成風險判斷
2. **高風險時，在手機上彈出提醒**：依 `REVIEW-STANDARD.md` 判定等級（D 危險／C 要小心／N 提醒／S 安全），並列出「守門員檢查發現」的白話理由。主要按鈕是「移除這個 App」；D 級要保留時需要二次確認，3 天後再提醒一次。**不依賴問家人**
3. 對家人的遠端推送：**MVP 暫時不做**，保留 `Notifier` 介面，之後再接 ntfy、Telegram、email 或企業微信
4. 每一個判斷都要能說出原因（可解釋），避免誤殺 LINE、銀行、政府 App

**非目標（Android 做不到，或不該做）**
- 擋下 YouTube 或其他 App 裡的廣告（沙盒限制）
- 靜默自動移除 App（需要 Device Owner，而設定它必須先恢復原廠）
- 使用無障礙服務讀取螢幕（Play 政策禁止；而且這正是詐騙 App 最常濫用的高風險權限）
- 讀取通知或聊天內容並上傳

## 3. 判斷規則（特徵），全部都在手機上本機計算

| # | 特徵 | 資料來源 | 實機依據 |
|---|---|---|---|
| F1 | 廣告聯播網 SDK 數量（AppLovin、Pangle、Mintegral、Vungle、InMobi、Bigo、Moloco、TradPlus、Yandex…；大陸版再加優量匯、快手、百度、Sigmob） | Manifest 元件名稱 + dex 字串 | 垃圾 App 普遍有 7–16 家；一般 App 通常 0–2 家 |
| F2 | App 外彈出元件：`PopupAdActivity`、`FullscreenAdService`、`OverlayActivity` | Manifest | 11 個垃圾 App 裡有 9 個 |
| F3 | App 外觸發器：監聽 `USER_PRESENT`、`SCREEN_ON`、`BATTERY_*`，或開機自動啟動 | Manifest receivers | QR Scanner、All PDF Reader、File Recovery |
| F4 | 元件名稱混淆（像 `ArraequitActivity`、`wiwri.rrwpw` 這種無意義的名稱） | Manifest + dex | All Document Reader、Document Viewer |
| F5 | 高風險類型：清理、加速、防毒、救援、省電、PDF 或文件閱讀器、QR、手電筒 | 名稱 + 套件名稱關鍵字 | 兩支手機的垃圾 App 幾乎都屬於這些類型 |
| F6 | 權限與功能不符（例如 PDF 閱讀器要求通知監聽、使用情況存取、顯示在上層） | 要求的權限 | Secure AntiVirus、Photo Recover Finder |
| F7 | **詐騙金流字串**：USDT、deposit bonus、staking、withdraw、入金、出金、提領、凍結資金、邀請碼佣金 | dex + 原生程式庫（例如 Flutter 的 `libapp.so`） | TGC、Finstar |
| F8 | 安裝來源：null、瀏覽器、通訊軟體（大陸版的權重更高） | `InstallSourceInfo` | — |

- **分級**：「高風險（疑似詐騙）」→ F7 命中；「廣告流氓」→ F1 + F2/F3/F4 的組合分數；「廣告多，但屬於一般 App」→ 只有 F1 偏高，例如 Candy Crush 這類遊戲。**這一級只列入週報，不打擾長輩**
- **白名單**：已知正常 App 與其簽章（LINE、銀行、健保、政府機關）；家人可以在 App 裡標記「我知道，保留」
- **規則打包在 App 內，隨版本更新**；不從遠端下載可執行程式碼

## 4. 系統架構

```
┌────────────── 長輩手機 ──────────────┐
│ Watcher (WorkManager 15min +           │
│   getChangedPackages / 開機 / 開 App)   │
│        │                               │
│ FeatureExtractor ─ PackageManager      │
│        │          + 讀 base.apk/splits │
│ RiskEngine (規則 JSON, 可解釋)          │
│        │                               │
│ ├─ 長輩端通知 → 大字說明頁 → ACTION_DELETE │
│ └─ Notifier ──HTTPS──► 家人手機          │
└────────────────────────────────────────┘
```

- **權限（MVP）**：`QUERY_ALL_PACKAGES`、`POST_NOTIFICATIONS`、`USE_FULL_SCREEN_INTENT`、`RECEIVE_BOOT_COMPLETED`、`REQUEST_DELETE_PACKAGES`。MVP 不做遠端推送，所以**連 `INTERNET` 都不需要**：守門員完全離線，也不可能外洩資料。**不需要**無障礙、使用情況存取或通知存取
- **彈窗的實作方式**：Android 10 以後，App 不能從背景直接啟動畫面。做法是**高優先級通知 + 全螢幕 intent**：Android 14 以後需要在設定中開啟「全螢幕通知」，首次設定時由家人協助開啟。如果沒有開啟，就改為 heads-up 通知，並在長輩下次解鎖或打開守門員時顯示說明頁。**不使用「顯示在其他 App 上層」**，因為這是詐騙 App 最常濫用的權限
- **家人通知管道**：MVP 不做（見第 8 節）；以後可選 ntfy（可自架）、Telegram bot、email，大陸版用企業微信。LINE Notify 已於 2025-03 停止服務
- **技術棧**：Kotlin、Jetpack Compose、WorkManager；minSdk 26，targetSdk 36
- **長輩端的介面原則**：語氣平穩、品牌一致；**不能長得像詐騙彈窗**（不用紅色閃爍，也不寫「立即處理」）

| 階段 | 內容 | 驗收門檻 | 預估 |
|---|---|---|---|
| **M0 技術驗證** | 在兩支實機上確認：一般 App 能讀到其他 App 的 `base.apk`；`getChangedPackages` 可用；WorkManager 在 ColorOS 與 OriginOS 上不會被系統殺掉；`ACTION_DELETE` 流程正常；**全螢幕通知在鎖屏與解鎖狀態下都能彈出** | 五項全部通過，否則修改架構 | 0.5 天 |

| **M3 實地試用** | 裝在兩支手機上一到兩週，記錄每一則警示是否正確 | 誤報 ≤ 1 次／週 | 1–2 週 |

## 6. 第二階段（MVP 穩定後）

- **推播垃圾偵測**（選用「通知存取」）：只在手機上統計推播頻率與同步推播模式，例如 3 個 App 在同一秒推送「News」；**不讀取也不上傳內容**
- **「安裝後從未開啟」偵測**（選用「使用情況存取」）
- **大陸版規則包**：大陸常見的 SDK 特徵、快應用偵測、企業微信通知、引導開啟純淨模式
- **週報**與簡易的家人檢視頁

## 7. 風險與對策

| 風險 | 對策 |
|---|---|
| 誤判正常 App，長輩因此不敢用手機 | 白名單、分級通知、反例 0 誤判的門檻、家人可以覆寫判斷 |
| 規則只對今天的樣本有效 | M1.5 外部驗證；持續補充新樣本 |
| 垃圾 App 改用動態載入或加殼，逃過靜態分析 | 第二階段加入行為訊號（推播、從未開啟） |
| 廠商系統殺掉背景程序 | M0 先驗證；首次設定時引導加入自啟動與電池白名單 |
| 守門 App 本身變成攻擊面 | 權限最小化、不做遠端程式碼更新、自簽並用 ADB 安裝、原始碼可供審查 |
| 通知太多造成疲乏 | 長輩端只推「高風險」與「廣告流氓」，其他列入週報 |

## 9. 資料與 repo 規則（為開源預作準備）

- `dataset/` 只放 **sha256、套件名稱、版本、標記（正例或反例）與來源說明**；APK 本體只放在本機的 `dataset-local/`（由 `EG_DATA` 指定），**不進 repo**
- 不收錄任何序號、通知內容、瀏覽紀錄或使用紀錄
- 規則檔（JSON）與測試報告可以公開

## 10. 介面設計原則（長輩會用、一般人也能用、要好看）

### 兩種角色、一個 App
- **主畫面**（預設）：只有一張大狀態卡片，加上一個主要按鈕
  - 狀態卡片：「✓ 手機目前安全」或「有 1 個 App 要先問孩子」
  - 主要按鈕：「現在檢查」
  - **完全不出現** SDK、權限、套件名稱這類術語
- **設定**（進階頁，不需要家人）：
  - 首次設定精靈：開啟全螢幕通知、依手機品牌引導加入電池與自啟動白名單、選用的上層彈窗
  - App 清單與判定理由、已保留的 App、歷史紀錄、審核標準說明（「守門員怎麼判斷？」）

### 長輩友善（依 WCAG 2.2 與高齡使用研究）
- 字級：內文至少 20sp、標題 28–34sp；支援系統字體放大到 200% 時版面不跑掉
- 對比：內文達到 AAA（≥ 7:1）；按鈕觸控區域至少 56–64dp
- **每頁只有一個主要動作**；不依賴滑動手勢；沒有計時、沒有倒數
- 用字：白話、正面、具體。例如寫「先問孩子」，而不寫「風險處置」
- 支援 TalkBack 朗讀、深色模式；語言支援繁中、簡中、英文

### 好看，而且看起來「值得信任」
- Material 3 + Jetpack Compose；**固定品牌配色，不使用動態配色**，讓長輩永遠認得「這是守門員」
- 溫暖、中性的配色（米白、深藍、琥珀色提示）；**不用紅色閃爍、驚嘆號轟炸、「立即處理」**。守門員的提醒絕對不能長得像它要對抗的詐騙彈窗
- 一致的 Logo 與吉祥物或圖示，讓長輩一眼就認得是真的守門員，而不是冒牌的
- 插圖取代文字說明（例如「問孩子」用一張簡單插圖表示）

### 設計流程（在寫正式 App 之前）
1. **可點擊的原型**（HTML），包含：長輩首頁、高風險彈窗、移除流程、家人設定精靈
2. **找 3–5 位長輩實測**（包含這次兩支手機的使用者），請他們完成：看懂提醒、選擇「先問孩子」、完成移除。記錄是否成功，以及在哪裡卡住
3. 依結果修改後才進入 M2

### 對「一般人使用」的影響
- 若將來上架 Play：`QUERY_ALL_PACKAGES` 必須符合 Play 政策的核心用途（防毒與安全類 App 屬於允許類別，**上架時需再確認最新政策**）
- 需要隱私權政策；MVP 完全離線、不蒐集資料，這一點會是最大的信任優勢
- 開源與否會影響信任度（安全類 App 開源，可以讓人檢驗「它自己不是流氓軟體」）

## 11. 安裝當下攔查與安全掃 QR（使用者需求，2026-09-25）

### 11.1 安裝當下攔查
- **機制**：常駐的前景服務註冊 `PackageInstaller.SessionCallback`（有 `QUERY_ALL_PACKAGES` 就能收到所有 App 的安裝工作），並動態接收 `PACKAGE_ADDED`
- **判斷來源**：從 `SessionInfo` 取得安裝者（Play 商店、系統安裝程式、Chrome、LINE…）、App 名稱與圖示、`originatingUri`
  - 來源**不是**官方商店，也就是 APK 側載 → **立即提醒**：「等一下！有 App 正要安裝，但它不是從商店來的。如果是網頁、影片或別人叫您裝的，請按『取消』。」
  - 來源是 Play 商店 → 安裝完成後**幾秒內**用第 3 節的規則掃描（取代原本的 15 分鐘排程，排程保留作為備援）
- **彈窗方式**：
  - 螢幕關閉或鎖定時：全螢幕通知（M0 已驗證可行）
  - **長輩正在使用手機時，Android 會把全螢幕通知降為上方橫幅** → 選用「顯示在其他 App 上層」權限，把提醒直接蓋在安裝畫面上。**這項權限預設關閉，由家人在設定時決定是否開啟**，並在隱私說明中寫清楚用途
- **限制**：看不到 YouTube 或網頁內容（不使用無障礙服務）；不能替使用者取消安裝，只能清楚提醒
- **新增權限**：`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_SPECIAL_USE`；選用的 `SYSTEM_ALERT_WINDOW`。仍然**沒有 `INTERNET`**

### 11.2 安全掃 QR 碼
- 守門員內建「掃 QR 碼」大按鈕，讓長輩不必下載廣告型 QR 掃描器
- 使用 CameraX 加上離線條碼辨識（ZXing，Apache-2.0；或 ML Kit 內建模型版），**不連網**
- 開啟前先在手機上檢查內容，可疑時先彈窗確認：
  - `.apk` 或下載連結、`intent://`、`market://`
  - LINE 或 Telegram 的群組邀請、加好友連結（投資詐騙最常見的入口）
  - 加密貨幣錢包地址、短網址、非 https、網域與顯示名稱不符
  - 一般網址：顯示「將要打開：網域名稱」，大字，讓長輩確認
- 新增權限：`CAMERA`

### 11.3 M0b 實機驗證（要在寫正式功能之前完成）
| # | 項目 | 門檻 |
