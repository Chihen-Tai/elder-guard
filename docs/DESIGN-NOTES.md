# 介面設計紀錄

- 設計前提（2026-09-25，使用者要求）：**長輩一個人拿著手機，身邊沒有家人，也要能自己安全處理**；介面要好看、人性化，一般人也能使用
- 實作：`android/`（Kotlin + Jetpack Compose + Material 3），固定品牌配色見 `ui/Theme.kt`
- 實機：vivo V2417，系統字體 **1.35 倍**（長輩實際設定）。截圖在 `design/shots/`（不進 repo），只在守門員位於最上層時才拍，並裁掉狀態列（`safe_shot.sh`）

## 原則（實作中已落實）

- 每頁只有一個主要動作，而且不必捲動就看得到
- 自己就能做出安全的選擇：主要按鈕是「移除」，並說明「照片和 LINE 不受影響」、「手機會再問一次，按『確定』」
- 「問家人」「撥 165」是輔助選項；165 按鈕只帶入號碼，不會直接撥出（`ACTION_DIAL`，不需要撥號權限）
- 不用紅色閃爍、不倒數、不寫「立即處理」，**守門員不能長得像詐騙彈窗**
- 固定品牌配色與盾牌標誌，讓長輩一眼認得是真的守門員
